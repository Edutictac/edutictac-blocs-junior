# Fitxa docent 4 — Ens presentem

| | |
|---|---|
| **Plantilla** | «4. Ens presentem» (pestanya **Reptes**) |
| **Edat orientativa** | 5-8 anys (Infantil 5 anys a 2n de Primària) |
| **Durada** | 30-45 minuts |
| **Agrupament** | Per parelles: una persona escriu els textos i l'altra col·loca els blocs; canvien a meitat sessió |
| **Material** | Una tauleta o ordinador per parella amb https://blocs-junior.edutictac.es |

## Objectiu

Programar un personatge que **parla** i començar un programa **tocant el personatge** en
lloc de la bandera verda.

L'alumnat descobreix que:

- un programa pot començar quan toquem un personatge;
- el bloc **Digues** mostra una bafarada amb el text que escrivim;
- els blocs **Digues** s'executen un darrere l'altre, com una conversa;
- podem copiar la idea d'un programa per fer-ne un de propi.

## Què hi ha a la plantilla

- **Junior**, a l'esquerra, ja programat: *en prémer-lo* → diu «Hola, soc Junior!» → diu
  «M'agrada programar!» → salta.
- **Tic** (el personatge blau), a la dreta, amb el bloc **Comença en prémer** i res més.
- L'escenari és una aula. La consigna a dalt: «Toca Junior. Després fes que Tic es
  presente!».

## Blocs que apareixen

| Bloc | Categoria | Per a què serveix |
|---|---|---|
| Comença en prémer | Inici (groc) | Comença el programa quan toquem el personatge a l'escenari |
| Digues | Aparença (lila) | Mostra una bafarada amb el text escrit |
| Salta | Moviment (blau) | El personatge bota cap amunt i torna a baixar |

## Desenvolupament

1. **Inici (5 min).** Roda de presentacions: cada alumne diu el seu nom i una cosa que li
   agrada. Així ho farà Tic.
2. **Obrir la plantilla (5 min).** Pestanya **Reptes** → «4. Ens presentem». Premem la
   bandera verda: no passa res. Toquem Junior: ara sí! Mirem el seu programa: comença amb
   una mà, no amb una bandera.
3. **Exploració (10 min).** Seleccionar Tic i arrossegar un bloc **Digues** darrere del
   bloc **Comença en prémer**. Tocar el text del bloc i escriure una salutació. Tocar Tic
   per provar.
4. **Repte (10-15 min).** Completar la presentació de Tic: nom, una cosa que li agrada i un
   moviment final. Després, fer que Junior i Tic es presenten un darrere l'altre tocant-los
   per torns.
5. **Tancament (5 min).** Cada parella presenta el seu Tic a la classe. Quina diferència hi
   ha entre començar amb la bandera i començar tocant el personatge?

## Solució

A Tic: `comença en prémer` → `digues «Hola, soc Tic!»` → `digues «M'agrada...»` →
`salta 2`

No hi ha una única solució: qualsevol presentació amb almenys un bloc **Digues** és
correcta. El moviment final pot ser qualsevol bloc blau.

## Errors habituals

- **Prémer la bandera verda.** Aquests programes comencen tocant el personatge a
  l'escenari, no amb la bandera.
- **Programar el personatge equivocat.** Els blocs es posen al personatge seleccionat a
  la llista de l'esquerra. Comproveu que Tic està marcat.
- **No trobar on s'escriu.** Cal tocar el text del bloc **Digues** perquè aparega el
  teclat.
- **Textos massa llargs.** La bafarada es talla o es fa difícil de llegir: millor diverses
  frases curtes, una a cada bloc.

## Ampliació

- Afegir un bloc **Espera** entre frases perquè es puguen llegir millor.
- Gravar la veu de l'alumnat amb el micròfon (categoria verda) i fer que Tic parle.
- Afegir un tercer personatge que es presente.
- Per a qui acaba abans: fer que en tocar Tic responga a Junior («Encantat, Junior!»).

## Observació i avaluació

| Indicador | Sí | Amb ajuda | Encara no |
|---|---|---|---|
| Distingeix l'inici amb bandera de l'inici en prémer | | | |
| Escriu un text en el bloc Digues | | | |
| Ordena diverses frases en seqüència | | | |
| Programa el personatge correcte | | | |

## Pensament computacional

- **Esdeveniments:** un programa pot començar per coses diferents (bandera, tocar).
- **Seqüència:** les frases apareixen en l'ordre dels blocs.
- **Reutilització:** partir d'un programa que ja funciona per crear-ne un de nou.
