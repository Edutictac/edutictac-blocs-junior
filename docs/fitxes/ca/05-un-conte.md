# Fitxa docent 5 — Un conte en 3 pàgines

| | |
|---|---|
| **Plantilla** | «5. Un conte en 3 pàgines» (pestanya **Reptes**) |
| **Edat orientativa** | 6-8 anys (1r a 3r de Primària) |
| **Durada** | 2 sessions de 45 minuts |
| **Agrupament** | Grups de 2 o 3: una persona inventa el final, una altra programa i una altra el conta en veu alta |
| **Material** | Una tauleta o ordinador per grup amb https://blocs-junior.edutictac.es. Opcional: full per dibuixar el final |

## Objectiu

Crear una **història animada en diverses pàgines** i inventar-ne el final. Els personatges
es coordinen amb **missatges** i el conte passa de pàgina amb **Vés a la pàgina**.

L'alumnat descobreix que:

- un projecte pot tindre diverses pàgines, com un llibre;
- el bloc **Vés a la pàgina** canvia d'escena, i en obrir-se una pàgina nova comencen els
  seus programes de bandera verda;
- un personatge pot enviar un missatge i un altre pot començar quan el rep;
- un conte té inici, nus i desenllaç.

## Què hi ha a la plantilla

- **Pàgina 1 (parc).** Text: «Junior se'n va d'excursió.». Junior: *bandera verda* → diu
  «Me'n vaig al bosc!» → avança 13 → **va a la pàgina 2**.
- **Pàgina 2 (bosc).** Text: «Al bosc es troba Tic.». Junior avança, diu «Hola, Tic!» i
  **envia el missatge taronja**. Tic, *en rebre el missatge taronja* → diu «Anem a la
  platja!» → salta → **va a la pàgina 3**.
- **Pàgina 3 (platja de nit).** Text: «Inventa tu el final del conte!». Junior i Tic
  només tenen la bandera verda: el final està per fer.

## Blocs que apareixen

| Bloc | Categoria | Per a què serveix |
|---|---|---|
| Comença en prémer la bandera verda | Inici (groc) | Comença el programa; també quan s'obri la pàgina |
| Envia missatge | Inici (groc) | Envia un missatge d'un color a tots els personatges |
| Comença en rebre missatge | Inici (groc) | Comença quan arriba un missatge d'aquest color |
| Digues | Aparença (lila) | Mostra una bafarada amb el text escrit |
| Mou-te a la dreta | Moviment (blau) | Mou el personatge cap a la dreta |
| Salta | Moviment (blau) | El personatge bota |
| Vés a la pàgina | Final (roig) | Passa a la pàgina triada |

## Desenvolupament

**Sessió 1**

1. **Inici (10 min).** Llegim o contem un conte curt i identifiquem inici, nus i final.
2. **Obrir la plantilla (10 min).** Pestanya **Reptes** → «5. Un conte en 3 pàgines».
   Premem la bandera i mirem tot el conte. Les pàgines es veuen a la dreta de l'editor.
3. **Llegir el codi (15 min).** Com sap Tic quan ha de parlar? Busquem el missatge
   taronja: Junior l'envia i Tic l'espera. Qui fa canviar de pàgina?
4. **Inventar el final (10 min).** En grup, decidim què passa a la platja i ho dibuixem o
   escrivim en tres frases.

**Sessió 2**

5. **Programar el final (30 min).** A la pàgina 3, afegir blocs a Junior i Tic per contar
   el final: diàlegs amb **Digues**, moviments i, si cal, un missatge perquè parlen per
   torns. Canviar el text de la pàgina si volem. Tancament: cada grup conta el seu conte
   en veu alta mentre es projecta.

## Solució

Oberta: cada grup inventa el seu final. Un exemple a la pàgina 3:

- Junior: `bandera verda` → `digues «Quina platja més bonica!»` → `envia missatge taronja`
- Tic: `comença en rebre missatge taronja` → `digues «Mira, estreles!»` → `salta 2`

L'important és que el final continue la història i que els personatges parlen en ordre.

## Errors habituals

- **Els dos personatges parlen alhora.** Si tots dos comencen amb la bandera, diuen les
  frases al mateix temps. Cal usar un missatge perquè un espere l'altre.
- **Missatge d'un altre color.** L'emissor i el receptor han de tindre el mateix color.
- **Programar en la pàgina equivocada.** Comproveu que la pàgina 3 està seleccionada abans
  d'afegir blocs.
- **Per veure només el final**, toqueu la pàgina 3 i premeu la bandera: no cal veure tot el
  conte cada vegada.

## Ampliació

- Afegir una quarta pàgina amb un altre escenari i un **Vés a la pàgina** al final de la
  tercera.
- Gravar la veu del grup contant el conte.
- Afegir un personatge nou dibuixat amb l'editor de pintura.
- Per a qui acaba abans: canviar el text de cada pàgina per fer un conte totalment nou.

| Explica com passa el conte d'una pàgina a l'altra | | | |

| Programa un final coherent amb la història | | | |
| Col·labora en el grup i respecta els torns | | | |

## Pensament computacional

- **Esdeveniments i missatges:** un personatge avisa un altre perquè actue.
- **Paral·lelisme:** diversos personatges tenen programes alhora.
- **Descomposició:** la història es divideix en pàgines i escenes.
- **Creativitat:** programar per contar alguna cosa pròpia.
